### ⚡ OVERVIEW

This project is a frontend authentication UI system designed with an ancient aesthetic using pure HTML, CSS, and JavaScript.
It provides a seamless experience for switching between Sign In and Sign Up interfaces without reloading the page, delivering a smooth and modern user flow.
<hr>

 ### ✨ KEY HIGHLIGHTS

🌑 Light theme interface<br>
⚡ Smooth transitions using iframe switching<br>
🎯 Clean and structured layout<br>
🧩 Modular file separation (Login / SignIn / SignUp)<br>
🔐 Authentication UI simulation (frontend only)<br>
📱 Responsive and lightweight<br>

<hr>

### 🔹 Sign In Flow
